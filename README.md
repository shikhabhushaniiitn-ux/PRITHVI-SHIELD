# PRITHVI-SHIELD

**A Multimodal AI and Geospatial Platform for Disaster Intelligence and Community Resilience**

PRITHVI-SHIELD is a research and educational project focused on satellite-based flood mapping, infrastructure exposure analysis, settlement accessibility and evidence-grounded disaster reporting.

## Initial Focus

The first development milestone targets the IIT Mandi Multimodal AI Hackathon 2026, Track B: Mapping Flood Damage from Space.

The initial system aims to:

* Map flood-related changes using permitted pre-event and post-event satellite observations.
* Estimate the exposure of mapped buildings, roads and bridges.
* Analyse road connectivity between settlements and essential facilities.
* Present results through a map dashboard and an evidence-backed situation report.

## Development Principles

* Modular architecture and reproducible workflows.
* Traceable data sources and processing steps.
* Explicit uncertainty, assumptions and limitations.
* Honest evaluation and appropriate data licensing.

## Project Status

**Status:** Initial environment setup.

Implementation, datasets, model performance and evaluation results will be documented as they become available.

## Intended Technology Stack

Python, Streamlit, NumPy, Pandas, geospatial processing libraries, Git and GitHub.

## Disclaimer

PRITHVI-SHIELD is a research and educational decision-support prototype. It does not replace official disaster warnings, emergency services or field verification.
